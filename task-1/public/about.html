About me

Who is behind these pages.

Background

I am a developer who cares about how things work underneath. I started with core web fundamentals and moved into backend engineering with PHP and MySQL, then into application security.

This site is the deliverable for Task 1 of the ApexPlanet Software Pvt. Ltd. Full Stack Web Development internship. Everything here is hand-written: semantic HTML, modern CSS, and vanilla JavaScript with no framework.

How I work

I prefer small, readable functions over clever abstractions, and I would rather fix a bug at the source than hide it. Every form I build gets the same treatment: server-side validation, prepared statements, escaped output.

Currently learning

Advanced PHP patterns, containerised development, and offensive security techniques in an isolated lab so I can understand the attacks I later defend against.

Principles

  1. 01

    Validate on the server

    Client-side checks are a convenience for the user, never a security control.

  2. 02

    Never build SQL by concatenation

    Prepared statements with bound parameters, every single time.

  3. 03

    Escape on output

    Context-aware escaping right before data reaches HTML.

  4. 04

    Accessible by default

    Semantic markup, visible focus, real labels, and reduced-motion support.
